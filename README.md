# 虎式 I 型重型坦克（后期生产型）三维数字复原

双端（PC / 手机）WebGL 数字展台。页面为**单文件**实现：three.js r128 内联、装甲迷彩与地面纹理均由代码生成的 Canvas 纹理生成，零外部依赖，任何静态托管可直接运行。

## 在线地址

**https://zero-william163.github.io/tiger-i/**

## 操作

- 鼠标（PC）：左键拖拽环绕视角、滚轮缩放；W/S 行驶、A/D 转向、Shift 加速；Q/E 炮塔旋转、R/F 俯仰、空格开火。
- 触屏（手机）：单指旋转视角、双指捏合缩放；底部按钮驾驶 / 自动旋转 / 结构模式 / 爆炸视图；左侧按钮一键视角。
- 右上角"技术参数"查看完整数据；左侧"结构"切换部件显示。

## 双端性能档位

页面按设备自动分档（`App.mobile` 判定：移动 UA 或触屏+窄窗）：

| 档位 | 像素比上限 | 阴影类型 | 阴影贴图 |
|---|---|---|---|
| 手机 | 1.5 | PCF | 1024×1024 |
| 桌面 | 2 | PCFSoft | 2048×2048 |

## 如何更新已发布的页面

1. 修改 `tiger_i_3d.html`；
2. 把它复制/重命名为 `index.html`，保持文件在仓库 `main` 分支**根目录**；
3. 在 GitHub 仓库页面 **Add file → Upload files** 上传覆盖，或直接 `git push`；
4. GitHub Pages 自动重新构建，约 1 分钟生效。
